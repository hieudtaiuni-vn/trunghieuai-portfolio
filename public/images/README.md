# THƯ MỤC HÌNH ẢNH DỰ ÁN (PUBLIC / IMAGES)

Thư mục này dùng để lưu trữ các tệp hình ảnh chính thức của website Portfolio Dương Trung Hiếu:

## 1. `portrait.jpg` (Ảnh chân dung chính thức)
- **Tên tệp:** `portrait.jpg` (hoặc `portrait.png`)
- **Kích thước khuyến nghị:** 800 x 900 px (tỷ lệ 4:5 hoặc 1:1)
- **Dung lượng tối ưu:** < 300 KB để đảm bảo tốc độ tải trang nhanh
- **Cách sử dụng:** Khi bạn chép ảnh chân dung thật vào đây với tên `portrait.jpg`, website sẽ tự động nhận diện và hiển thị ảnh thay thế cho khung monogram DTH.

## 2. `og-cover.jpg` hoặc `og-cover.png` (Ảnh xem trước khi chia sẻ mạng xã hội)
- **Tên tệp:** `og-cover.jpg` (hoặc đang dùng tệp vector mẫu `og-cover.svg`)
- **Kích thước chuẩn:** 1200 x 630 px
- **Dung lượng tối ưu:** < 400 KB
- **Mục đích:** Hiển thị thẻ card xem trước trên Facebook, Zalo, LinkedIn, iMessage khi gửi link https://trunghieuai.io.vn.
